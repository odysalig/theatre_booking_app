Theatre Booking Mobile App
Περιγραφή
Η εφαρμογή επιτρέπει στους χρήστες να κάνουν κρατήσεις θέσεων σε θεατρικές παραστάσεις μέσω mobile εφαρμογής.
Αποτελεί ένα πλήρες κατανεμημένο σύστημα που περιλαμβάνει:
•	Frontend 
•	Backend 
•	Βάση Δεδομένων 

Λειτουργικότητα
 Authentication
•	Εγγραφή χρήστη (Register)
•	Σύνδεση χρήστη (Login)
•	Χρήση JWT για authentication
•	Ασφαλής αποθήκευση token στη συσκευή

 Προβολή Παραστάσεων
•	Λίστα διαθέσιμων παραστάσεων
•	Προβολή θεάτρου, διάρκειας και πληροφοριών
•	Επιλογή παράστασης

 Showtimes
•	Προβολή διαθέσιμων ημερομηνιών και ωρών
•	Προβολή αίθουσας και τιμής
•	Προβολή διαθέσιμων θέσεων
Κρατήσεις

•	Δημιουργία κράτησης (Reservation)
•	Έλεγχος διαθεσιμότητας θέσεων
•	Αυτόματη ενημέρωση διαθέσιμων θέσεων

Διαχείριση Κρατήσεων
•	Προβολή κρατήσεων χρήστη
•	Κατάσταση κράτησης (ACTIVE / CANCELLED)
•	Ακύρωση κράτησης
•	 Επεξεργασία αριθμού θέσεων (Edit Seats)

Περιγραφή Λειτουργικότητας
Η εφαρμογή επιτρέπει στους χρήστες να περιηγούνται σε διαθέσιμες θεατρικές παραστάσεις και να πραγματοποιούν κρατήσεις θέσεων.
 Οι παραστάσεις προβάλλονται οργανωμένες ανά θέατρο, ενώ κάθε παράσταση μπορεί να εμφανίζεται σε διαφορετικές ημερομηνίες και ώρες (showtimes).
 Κάθε προβολή πραγματοποιείται σε συγκεκριμένη αίθουσα (hall) του θεάτρου και διαθέτει δική της τιμή και αριθμό διαθέσιμων θέσεων.
Ο χρήστης μπορεί να δημιουργήσει λογαριασμό και να συνδεθεί, ώστε να έχει πρόσβαση στις λειτουργίες της εφαρμογής.
 Στη συνέχεια, μπορεί να επιλέξει μια παράσταση, να δει τις διαθέσιμες ημερομηνίες και ώρες και να πραγματοποιήσει κράτηση επιλέγοντας τον αριθμό των εισιτηρίων.
 Το σύστημα ελέγχει τη διαθεσιμότητα σε πραγματικό χρόνο και ενημερώνει τις θέσεις μετά από κάθε κράτηση.
Επιπλέον, ο χρήστης μπορεί να δει το ιστορικό των κρατήσεών του, να ακυρώσει μια κράτηση ή να τροποποιήσει τον αριθμό των θέσεων.
Οδηγίες Χρήσης
Για την εκτέλεση της εφαρμογής πρέπει πρώτα να έχει δημιουργηθεί η βάση δεδομένων theatre_booking_app στη MariaDB μέσω του αρχείου schema.sql.
Στη MariaDB χρησιμοποιούνται ενδεικτικά τα παρακάτω στοιχεία σύνδεσης:
DB_USER=root
DB_PASSWORD=password
DB_NAME=theatre_booking_app
Στη συνέχεια, ανοίγουμε terminal μέσα στον φάκελο backend και εκτελούμε:
npm install
npm run dev
Η εντολή npm install εγκαθιστά τα απαραίτητα backend dependencies, ενώ η εντολή npm run dev ξεκινά τον Node.js / Express server.
Τέλος, ανοίγουμε δεύτερο terminal μέσα στον φάκελο frontend και εκτελούμε:
npm install
npx expo start -c
Η εντολή npm install εγκαθιστά τα απαραίτητα frontend dependencies, ενώ η εντολή npx expo start -c ξεκινά την React Native εφαρμογή μέσω Expo και καθαρίζει την cache.
Για να λειτουργεί σωστά η εφαρμογή, το baseURL στο αρχείο frontend/services/api.js πρέπει να δείχνει στη διεύθυνση του backend server, για παράδειγμα:
baseURL: 'http://192.168.1.8:3000/api'
Αν χρησιμοποιείται κινητό μέσω Expo Go, το κινητό και ο υπολογιστής πρέπει να είναι συνδεδεμένα στο ίδιο δίκτυο WiFi και να αλλαχτεί η ip με την ip στην οποία είναι συνδεδεμένες αυτές οι συσκευές.
